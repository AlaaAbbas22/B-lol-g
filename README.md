# 📝 The B-lol-g

A personal blogging platform built with **Next.js**, **Tailwind CSS**, and **Supabase**. This app allows you to write, edit, and share posts with a smooth user experience and modern UI.

You can check it out live at: [https://b-lol-g.vercel.app/](https://b-lol-g.vercel.app/)

![{87B89CFC-2044-499C-B423-5BE22F9DFB5A}](https://github.com/user-attachments/assets/ea7f4091-5bd0-4527-b287-0f71b73f4b4b)

## 🛠 Tech Stack

- **Frontend & Backend**: [Next.js](https://nextjs.org/)  
- **Styling**: [Tailwind CSS](https://tailwindcss.com/)  
- **Database & Auth**: [Supabase](https://supabase.com/)
